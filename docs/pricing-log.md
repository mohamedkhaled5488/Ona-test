# Pricing log

One line per pricing change. Prices change only in Play Console / RevenueCat, never in a build.

How to run a test:

- Change **one thing at a time**.
- Wait **at least two weeks** before deciding.
- Judge by **revenue per install**, not conversion rate alone. A cheaper price that converts more can still earn less.
